# Welcome TPU

Клиентская часть веб-платформы «Welcome TPU».

Что нужно установить

\[Node.js]
Git

Как запустить

bash
git clone https://github.com/Estuss/WelcomeTPU.git
cd WelcomeTPU/frontend
npm install
npm run dev

После запуска открыть в браузере http://localhost:5173
Структура проекта

src/
api/          запросы к бэкенду
assets/       картинки и иконки
components/   общие компоненты (шапка, подвал)
pages/        страницы сайта
App.jsx       маршруты
main.jsx      точка входа
index.css     стили
